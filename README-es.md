# Multiversal Demo

Multiversal es un juego desarrollado con HaxeFlixel.
Este repositorio contiene el código fuente completo de la demo del proyecto.

---

## 🛠️ Cómo compilar el juego

### 1. Instala Haxe

https://haxe.org/

---

### 2. Ejecuta los siguientes comandos en la terminal

```
haxelib setup
```

(Pulsa Enter cuando aparezca `Path:`)

```
haxelib install lime
haxelib install flixel
haxelib run lime setup flixel
haxelib run lime setup
```

(Pulsa `y` cuando se te pregunte)

```
haxelib run flixel-tools setup
```

(Pulsa `y` en las preguntas, selecciona tu editor e introduce la contraseña si es necesario)

---

### 3. Instala un editor de código

* Visual Studio Code (recomendado): https://code.visualstudio.com/
* Sublime Text: https://www.sublimetext.com/
* FlashDevelop: https://github.com/fdorg/flashdevelop
* IntelliJ IDEA: https://www.jetbrains.com/idea/

---

### 4. Instala Git

https://git-scm.com/

---

### 5. Descarga el proyecto

Abre la terminal en la carpeta que desees (por ejemplo, Documentos) y ejecuta:

```
git clone https://github.com/Azeouza/Multiversal-DEMO.git
```

---

### 6. Compilar el juego

Entra en la carpeta del proyecto:

```
cd Multiversal-DEMO
```

Y ejecuta el comando correspondiente según tu plataforma:

* Windows:

```
lime build windows
```

* Linux:

```
lime build linux
```

⚠️ En Linux, puede que sea necesario instalar VLC para la reproducción de vídeo:

```
sudo apt install vlc
```

* macOS:

```
lime build mac
```

* Neko (modo rápido para realizar pruebas):

```
lime test neko
```

---

## 💡 Consejos

* Los archivos ejecutables se encuentran en:

```
Multiversal-DEMO/export/<plataforma>/bin
```

* Para ejecutar el juego automáticamente después de compilar:
  → sustituye `build` por `test`

Ejemplo:

```
lime test windows
```
